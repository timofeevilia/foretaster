Open-source scanner for AI agents

Foretaster checks the tools connected to an AI assistant for hidden commands before the assistant reads them

It reads agent configuration files and the descriptions of connected tools, and reports poisoned descriptions, exposed keys and risky settings. The check on this page runs entirely in your browser, so nothing you paste leaves your computer.

How the attack works

A tool's description is read by the model, not by a person

Connecting a tool to an assistant looks like installing a plug-in, and it carries a risk that is easy to miss.

1

A tool is connected to the assistant and gives it access to, for example, mail, files or a calendar.

2

The tool arrives with a text saying what it can do, and the model reads that text in full as an instruction.

3

If a command is hidden in the text, such as reading the file with the keys and not reporting it, the assistant may carry it out.

Try it

Paste an agent configuration or a tool list and see what the scanner reports

The field accepts the configuration file of Claude Desktop, Claude Code, Cursor, VS Code or Windsurf, or a saved list of a server's tools. Two examples with typical problems are provided.

The scanner is downloaded once, about 15 MB, and then runs on your device. This page is not allowed to connect to any other site, and it stores nothing.

What it looks for

Nineteen checks in three groups

Tool descriptions

Instructions addressed to the model, invisible characters, references to key files, requests to hide an action from the user, parameters built to carry data out, and attempts to control the tools of another server.

Configuration

Keys and tokens stored in plain text, packages downloaded without a fixed version, connections without encryption, servers started through a shell script, look-alike package names and access to the whole disk.

Changes and combinations

A description that changed after it was approved, identical tool names on different servers, and an assistant that can at once read private data, take in outside content and send data out.

Measurements

A high result is obtained on attacks whose devices were already known

The scanner was measured on two public collections of attacks. The figures differ almost threefold, and both are shown because either one alone would mislead.

First collection

Attacks from the collection on which the rules were improved; the figures are for the part set aside and not looked at.

Second collection

Attacks by three other authors, never used for tuning.

  • Rules based on patterns find attacks whose wording someone has already seen. Attacks written in ordinary business language mostly pass.
  • On the first collection 1 of 160 genuine tools was flagged by mistake. In the second, 4 of 8 harmless tool lists were flagged; they were written as traps, such as a manager of SSH keys.
  • An automatic check supplements caution about what is connected to an assistant and does not replace it.

Method, limits and full tables

On your own machine

One command checks every agent configuration found on the computer

It needs the free uv tool and installs nothing permanently. The scanner only reads files, it does not start or contact any server unless asked to, and its reports can be read by GitHub code scanning.

uvx --from git+https://github.com/timofeevilia/foretaster foretaster scan
