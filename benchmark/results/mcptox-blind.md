# Benchmark results: mcptox

Scanner: foretaster 0.0.1. This file is generated by `python -m benchmark run`; do not edit it by hand.

## Corpus

Tool-poisoning attacks built on 45 real-world MCP servers. Source: https://github.com/zhiqiangwang4/MCPTox-Benchmark at revision `630121b3275f`, licence CC BY 4.0 (MCPTox contributors).

- 485 poisoned tool definitions
- 362 real tool definitions from 45 servers
- Note: Poisoned tools carry no parameter schema, so parameter rules cannot fire on them.
- Note: Clean tools are parsed back from rendered prompt text.
